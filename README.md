# bey-tracker

Small tool I use to keep track of BeybladeX prices across HK and JP
marketplaces (Carousell, Yahoo Auction JP, Mandarake, Mercari).

It is manual: paste a listing URL, the price I saw, what Bey it is.
The app shows me the cheapest historical entry per Bey, so I can
decide if a current listing is fair.

No scraping. The marketplaces do not love it, and honestly entering
things by hand keeps the dataset small enough to stay useful.

## run

    npm install
    npm run dev
